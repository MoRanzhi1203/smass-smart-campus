# SMASS 三端使用手册

> 一套系统，三个角色化界面：学生工作台 / 教师工作台 / 管理控制台。
> 启动：`python manage.py runserver 127.0.0.1:8050 --settings=smass.settings_product`

---

## 1. 登录

唯一入口：`http://127.0.0.1:8050/login/`

- 输入学校分配的登录名与密码；
- 登录成功后，系统按角色自动进入对应工作台（管理 > 教师 > 学生）；
- 一个账号拥有多角色时，顶部"切换工作台"可在允许的端之间切换；
- 无角色账号进入 `/no-role/`，提示联系管理员分配角色；
- 退出使用顶部用户区的退出按钮（POST，防 CSRF 跨站退出）。

## 2. 学生工作台

入口：`/student/`

### 2.1 导航

```
我的学习   学习工作台 · 我的课表 · 我的课程 · 学籍信息
日常事务   考勤与请假 · 场地预约 · 费用与账单 · 我的寝室
校园生活   活动与志愿 · 社团 · 学生组织 · 志愿服务
消息       通知公告 · 个人中心
```

### 2.2 可用操作

| 操作 | 位置 | 结果 |
|---|---|---|
| 提交请假 | 考勤与请假 → 右侧表单 | 生成 `LeaveRequest(status=submitted)`，教师/辅导员端出现待办 |
| 撤销请假 | 考勤与请假 → 我的请假 | 仅本人、且状态为待审批 |
| 自助缴费 | 费用与账单 → 缴纳 | 生成 `Payment` 与 `LedgerEntry`，账单状态刷新 |
| 申请场地 | 场地预约 → 申请 | 需审批的场地进入 `pending`，否则直接生效 |
| 取消预约 | 场地预约 → 取消 | 释放时段，可被再次预约 |
| 报名活动 | 活动与志愿 → 报名 | 生成报名；满员进入候补 |
| 取消报名 | 活动与志愿 → 我的报名 | 候补自动递补 |
| 申请入社 | 社团 → 申请加入 | 生成待审批成员关系 |

### 2.3 数据口径

- 课表：当前学期**已发布**的排课运行，按本人选课匹配；
- 考勤达标率 = （出勤 + 迟到）/ 全部考勤记录；
- 志愿时长与学分只统计**已认定**记录；
- 待缴金额 = 应缴 − 已缴（排除已取消账单）；
- 没有数据时显示空状态，不显示占位数字。

## 3. 教师工作台

入口：`/teacher/`

### 3.1 导航

```
教学工作   教学工作台 · 我的课程 · 教学班 · 我的课表
学生事务   考勤管理 · 学生事务 · 审批中心
辅导员工作 负责班级 · 负责学生 · 请假审批     ← 仅被授予辅导员关系时出现
消息       通知与公告 · 个人中心
```

### 3.2 可用操作

| 操作 | 位置 | 结果 |
|---|---|---|
| 发起考勤 | 考勤管理 → 发起考勤 | 生成场次与签到码 |
| 登记考勤 | 考勤登记 → 逐人登记 | 学生端考勤记录同步 |
| 结束考勤 | 考勤登记 → 结束考勤 | 关闭场次，禁止继续登记 |
| 审批请假 | 审批中心 / 请假审批 | 学生端状态同步为已批准/已驳回 |
| 审批补签 | 审批中心 | 补签记录生效 |
| 完成流程待办 | 审批中心 | 工作流实例推进 |
| 审批场地预约 | 审批中心 | 申请人端状态同步 |
| 查看学生档案 | 学生事务 → 查看 | 仅本人教学班/负责班级学生 |

### 3.3 辅导员扩展

辅导员不是新账号类型，而是教师账号上的组织关系：

```
OrganizationMembership(account=教师账号, unit=班级, role='counselor')
```

- 菜单自动出现"辅导员工作"分组；
- 后端守卫同时生效：无该关系访问 `/teacher/classes/` 返回 403；
- 负责学生范围 = 负责班级及其子单元的学生。

## 4. 管理控制台

入口：`/admin/`

### 4.1 导航

```
总览       控制台总览
身份与组织 用户账号 · 角色与权限 · 组织架构
学籍与教学 学籍管理 · 学籍异动 · 学年学期与课程 · 教学班与选课
排课与资源 排课与课表 · 教室与场地 · 预约审批
审批与工作流 待办与审批 · 流程定义
校园业务   活动管理 · 社团与学生组织 · 通知公告
数据治理   数据导入导出
运维与安全 运行监控 · 安全审计 · 系统配置（仅系统管理员）
```

### 4.2 可用操作

| 操作 | 权限 |
|---|---|
| 创建账号、分配/撤销角色、停用、重置一次性口令 | 系统管理员 |
| 查看用户与组织（本院范围） | 学院管理员 |
| 学籍查询与筛选 | 两者（范围不同） |
| 转专业 / 学籍异动审批 | 两者（限范围内学生） |
| 请假 / 场地预约审批 | 两者（限范围内学生） |
| 活动发布 / 结束 | 系统管理员 |
| 公告创建 / 发布 | 系统管理员 |
| 导入数据集查看与进入导入中心 | 两者 |
| 运行监控 / 安全审计 | 两者 |
| 权限矩阵、字段策略、密码策略 | 系统管理员 |

### 4.3 一次性口令

创建账号或重置口令时，系统生成随机口令并在页面消息中**只显示一次**；
敏感响应带有 `no-store` 缓存头。账号首次登录需修改密码。

## 5. 角色与落地页对照

| 角色 | 落地页 | 可访问 |
|---|---|---|
| 系统管理员 | `/admin/` | 管理控制台全部 |
| 学院管理员 | `/admin/` | 管理控制台（本院范围，系统级写操作 403） |
| 教师 | `/teacher/` | 教师工作台 |
| 教师 + 辅导员 | `/teacher/` | 教师工作台 + 辅导员分组 |
| 学生 | `/student/` | 学生工作台 |
| 无角色 | `/no-role/`（403） | 仅个人中心与通知 |
| 匿名 | `/login/` | 仅登录页 |

> 管理权限不等于数据权限：超级管理员若未持有学生角色，访问 `/student/` 同样 403。

## 6. 常见问题

**Q：登录后提示"账号尚未分配角色"？**
联系系统管理员在「管理控制台 · 用户账号」分配角色；角色变更后重新登录即可。

**Q：教师看不到"辅导员工作"？**
需要学院管理员/系统管理员在组织关系中授予
`role='counselor'` 的班级关系，而不是只给教师角色。

**Q：学生课表为空？**
当前学期必须有**已发布**的排课运行，且学生有有效选课记录。
两者缺一都会显示空状态而不是假数据。

**Q：学院管理员看不到某学生？**
数据范围由 `scope_college` 决定；组织编码或名称必须与该字段匹配。

**Q：想回到旧版入口？**
`/r4/`–`/r9/`、`/r11/`–`/r20/` 深层功能页仍在，可通过管理控制台的
"进入管理 / 前往…"按钮访问；`/r10/` 与 `/hub/` 已重定向到产品页。
