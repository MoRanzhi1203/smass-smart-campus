# SMASS R2.2 并发与浏览器报告（Concurrency & Browser）

## 1. MySQL 连接容量诊断（H5 核心发现）

| 指标 | 实测值 |
|---|---|
| `max_connections` | **20** |
| `Max_used_connections` | 21 |
| `Threads_connected` | 1（空闲） |

这解释了上一轮"并发 50 出现 107 次 `OperationalError:1040`"的根因：
**服务器只允许 20 个并发连接**，不是代码缺陷。

### 1.1 并发 ramp 重测（同一合成库 1,146 账号）

| 并发 | 成功 | 失败 | 说明 |
|---|---|---|---|
| 1 | 5/5 | 0 | — |
| 10 | 50/50 | 0 | — |
| **20** | **100/100** | **0** | 恰好等于 `max_connections` |
| 50 | 143/250 | 107 × `1040` | 超过连接上限 |

**结论：安全并发上限 = 20。** 超过即建连失败，事务未开始，因此**无半写数据**。
