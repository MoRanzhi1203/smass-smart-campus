# 05 组织与教学数据（campus 实测）

---

## 1. 组织层级

| 层级 | 数量 | 规则 |
|---|---|---|
| 学院 | 10 | 真实名称（计算机/机械/外语等） |
| 专业 | 35 | 挂靠学院，编号 `MAJ-<学院><序号>` |
| 年级 | 4 | 2023–2026 级 |
| 行政班 | 560 | 命名 `{专业}{年份}级{n}班`，父级为专业 |

校验：`class_parent_is_major` 通过（0 例外）。

## 2. 学生

| 项 | 结果 |
|---|---|
| 学籍 / 档案 / 账号 | 16800 / 16800 / 16800（三元组一致） |
| 学号 | `S{入学年}{5 位序号}`（10 位，唯一） |
| 状态分布 | 在读 / 毕业 / 休学（按年级规则） |
| 每班人数 | 30 |
| 课程 | 每生 8 门（专业 6 + 公共 2） |

## 3. 教师与岗位

| 角色 | 数量 | 依据 |
|---|---|---|
| 教师 | 1120 | 周学时 ÷ 12（每班 8 门 × 2 节） |
| 辅导员 | 27 | 每 8 班 1 人 |
| 班主任 | 560（每班 1 人） | 从本班任课教师中选 |
| 学院管理 | 30 | 每院 3 人（admin / academic_staff / student_affairs） |
| 宿管 | 34 | 32 栋 + 主管 + 维修 |

最小权限：仅 `dev_admin` 拥有 `system_admin`；学院管理统一 `college_admin`。

| 项 | 结果 |

| 项 | 结果 |
