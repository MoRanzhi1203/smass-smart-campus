# 06 宿舍与校园生活（campus 实测）

---

## 1. 宿舍资源

| 项 | 结果 |
|---|---|
| 宿舍区 / 楼栋 | 1 区 / **32 栋**（1 号学生公寓 …） |
| 寝室 | 3840（每栋 120 间，4 人间） |
| 床位 | 15360 |
| 在住 | **14280**（16800 × 85%） |
| 入住率 | 92.9% |
| 宿管范围 | 34 条（32 楼 + 主管 + 维修） |

## 2. 业务规则验证

| 规则 | 验证 |
|---|---|
| 一名学生仅一条活跃住宿 | `dorm_active_unique` 通过（重复 0） |
| 一张床仅一人 | 同上（重复 0） |
| 寝室不超容量 | `room_within_capacity` 通过 |
| 床位占用 = 活跃分配 | **14280 = 14280** |
| 楼栋/寝室停用前校验在住 | 服务层拒绝（测试覆盖） |
| 宿管只能管授权楼栋 | 越权审批实测 **403** |

## 3. 业务单据

| 类型 | 数量 | 状态覆盖 |
|---|---|---|
| 调宿申请 | 34 | completed / submitted / rejected |
| 退宿申请 | 16 | submitted / completed |
| 报修 | 60 | 5 种状态（待分派→已分派→处理中→完成→关闭） |
| 巡查 | 40 | 正常 / 问题（含复查推进） |

## 4. 校园生活

| 项 | 结果 |
|---|---|
| 社团 | 20（4 类：社团/协会/团委/学生会），500 成员，20 名负责人 |
| 活动 | 40 场（讲座/社团/第二课堂/志愿），800 报名（含候补与签到） |
| 志愿时长 / 学分 | 仅对已结束活动生成 |
| 财务 | 3 收费项 / 16800 账单（6800 元）/ 10125 缴费（60%） |
| 通知 | 400 条站内通知，收件人均为真实账号 |

## 5. 内容自然化（详见 07）

- 楼栋：`1 号学生公寓`、寝室：`101 室`、宿舍区：`东区学生公寓`；
- 页面不再显示 `SIM-` 内部编码；
- 后台仍保留 `extra.sim_batch` / `SimulationBatch` / `synthetic_bank` 等合成标记。

## 6. 限制

- 楼栋内部编码仍为 `SIM-DORM-*`（仅后台）；
- 调宿/退宿申请数量较少（34/16），用于演示状态而非压力测试；
- 未做“按班级一键分床”的批量回归（功能已实现，见 V2.1 文档）。
