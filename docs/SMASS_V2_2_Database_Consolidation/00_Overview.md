# 00 总览（V2.2 三库归一）

> 一句话：**SMASS 从此只依赖并长期维护 `smass_campus` 一套校园业务数据库。**

---

## 1. 背景

V2.0/V2.1 期间形成了三个并行库：

| 库 | 角色 | 问题 |
|---|---|---|
| `smass_product_dev` | 产品开发库（三端演示） | 仅 7 学籍/5 教师，规模不足 |
| `smass_simulation` | 仿真库（large，16800 学生） | 定位为“仿真”，不应作为长期业务库 |
| `smass_unified_verify` | 统一迁移验证库 | 结构落后，无业务价值 |

用户决定：三库退出，唯一保留 `smass_campus`。

## 2. 最终格局

| 类型 | 数据库 |
|---|---|
| 长期业务库 | **`smass_campus`** |
| 测试库 | `test_smass_campus`（测试框架临时创建/销毁） |
| 已退役 | `smass_product_dev` / `smass_simulation` / `smass_unified_verify`（逻辑退役，待授权物理删除） |
| 严禁重建 | `smass`（历史库，已删除） |

## 3. 交付内容

| 项 | 结果 |
|---|---|
| 新库 | `smass_campus`：143 表 / 56 迁移，从零迁移 |
| 数据 | 16800 学生 / 1120 教师 / 560 班 / 4480 教学班 / 134400 选课 / 32 栋 / 15360 床 / 14280 住宿 / 20 社团 / 40 活动 / 16800 账单 |
| 配置 | `smass.settings_campus`，`manage.py` 默认即此 |
| 验收 | 完整性 15/15；浏览器 24/24；写操作 PASS（含越权 403）；回归 156 + 28 例全绿 |
| 文档 | 本目录 13 份 |

## 4. 关键决策

1. **不跨库复制**：large 数据用确定性生成器在同一 seed 下在 campus 重建，避免 PK/学号/登录名冲突；
2. **保留唯一超管**：`dev_admin`（system_admin）从产品库复制；
3. **内容去仿真化**：名称层全部自然化，后台保留 `sim_batch`/`SimulationBatch` 标记；
4. **物理删除需单独授权**：本次只做逻辑退役。
