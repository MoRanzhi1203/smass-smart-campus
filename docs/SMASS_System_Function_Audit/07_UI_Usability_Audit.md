# 07 UI 与实际可用性审计

> 方法：`scripts/audit_ui_probe.py` 用 Django 测试客户端以真实演示账号登录，
> 逐页 GET 并解析 HTML（标题、H1、正文长度、表格数、表单数、空状态、历史链接）；
> 结合 `scripts/product_e2e.py`（Chromium 27 项）、`scripts/product_smoke.py`（71 页）
> 与 17 张浏览器截图。原始数据：`inventory/ui_probe.json`、`inventory/ui_probe.md`。
>
> **口径说明**：`forms` 统计包含全局退出表单（每个页面 1 个），
> 因此"表单数 = 业务表单 + 1"。`legacy_links` 统计 `href="/rN"`。

---

## 1. 总体结果

| 角色 | 页面 | HTTP 200 | 有表格 | 有空状态 | 正文最短 | 历史链接 |
|---|---|---|---|---|---|---|
| 学生 | 15 | 15 | 7 | 4 | 281 字符 | 0 |
| 教师 | 10 | 10 | 7 | 2 | 262 字符 | 0 |
| 辅导员 | 3 | 3 | 2 | 1 | 332 字符 | 0 |
| 管理 | 22 | 22 | 19 | 6 | 207 字符 | **3** |
| 合计 | **50** | **50** | 35 | 13 | 207 | 3 |

结论：

- **没有"只有标题、没有内容"的页面**：最短正文 207 字符（管理端数据交换页，
  主体是数据集表/空状态 + 说明），且 50 页全部 200。
- 学生/教师/辅导员端**没有任何历史 R 链接**；管理端仅 3 个，全部标注"（专业工具）"。
- 13 个页面在演示数据下显示空状态，均有明确说明与下一步动作（见 §3）。

## 5. 重点检查项逐条结论

| 检查项 | 结论 | 证据 |
|---|---|---|
| 只有标题没有实际内容 | **无**（50 页最短正文 207 字符） | `ui_probe.json` |
| 列表一直为空且缺创建/导入入口 | 学生端多为真实空状态；管理端学籍空状态有"数据导入"入口；活动/场地/教务空状态有创建表单 | 探针 + 截图 |
| 按钮只是占位 | **未发现**：抽查按钮均指向真实路由或提交表单 | 40 例测试 + E2E |
| 需要跳回历史 R 系列专业工具 | 管理端 3 处（导入 `/r4/import/`、排课 `/r11/plan/`、流程 `/r6/definitions/`），均标注"（专业工具）" | 探针 `legacy_links=3` |
| 不同页面重复功能 | 通知公告 ↔ 通知中心（学生/教师）；公告管理 ↔ 通知中心（管理） | 页面代码 |
| 同一业务在学生端与教师端数据不一致 | 请假状态一致（测试 8/8）；课程/课表同源 | `product_consistency.py` |
| 管理端能查看但无法实际管理 | 组织架构、社团、流程定义、排课求解、导入导出、数据导出 | 见 §4 |
| 表面权限正确但直接访问 URL 越权 | **未发现**：越权均为 403 | 40 例 + 探针 + E2E |

## 6. 响应式与可访问性

| 项 | 实测 | 证据 |
|---|---|---|
| 移动端 390×844 | 学生首页/管理首页/课表页均无整页横向溢出 | 截图 20–23 + `scrollWidth==clientWidth` |
| 抽屉导航 | 汉堡按钮可展开，遮罩可关闭，Esc 关闭 | `static/workspace/app.js` |
| 跳过导航 | `.ws-skip` 链接 | `base.html` |
| 焦点/aria | 导航 `aria-current`、按钮 `aria-label`、抽屉 `aria-expanded`、通知角标 `aria-label` | `base.html` |
| 减少动效 | `prefers-reduced-motion` 关闭过渡 | `app.css` |
| 课表可读性 | 表格横向滚动容器（移动端 `min-width:640px`） | `app.css` |
| 颜色对比 | 主文本 `#0f172a` 对白底、侧栏 `#a8b6c9` 对深底，满足常规对比 | `app.css` 变量 |
| 键盘可达 | 表单/按钮为原生元素；切换器为 button | 模板 |

> 未做完整的 WCAG 自动扫描（`smass_a11y` 是独立配置的测试套件，
> 产品配置未接入）。本项结论限于人工抽查与截图。
