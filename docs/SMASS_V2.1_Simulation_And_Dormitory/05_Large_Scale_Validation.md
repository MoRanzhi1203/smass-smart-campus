## 4. 过程中修正的问题

排课教室容量原按固定 3 栋 × 80 间 = 240 间，large（560 班）不足，贪心排课报
“排课空间不足”。改为**按班级数动态计算**：

```
教室数 = ceil(班级数 × 1.2)   （560 班 → 672 间，9 栋）
```

依据：每班每周 8 次课、每次 2 节连排，共 8 个双节槽；15 个可用双节槽下，
同时占用率约 53%；1.2 倍冗余保证贪心可解。medium 216 班 → 260 间（4 栋）。

## 5. 结论与限制

- large 档可生成、可校验、可清理（清理按 `SIM-` 前缀与依赖顺序）；
- 耗时线性可控（3.2 分钟），无 O(n²) 行为；
- 未对 large 做浏览器走查（页面结构与 medium 相同，性能采样已覆盖）；
- 未做并发压测。
