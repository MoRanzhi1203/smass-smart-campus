# SMASS R2.2.1 切换与回滚演练（Cutover & Rollback Drill）

## 1. 本轮新增证据

| 演练 | 库 | 规模 | 结果 |
|---|---|---|---|
| G8 切换+回滚（H2） | `smass_r22_g8_drill` | 100 合成账号 | **PASS**（沿用上轮，本轮未重跑） |
| **万级回滚** | `smass_r22_g221_scale` | **10,000 合成账号** | **PASS** |

### 1.1 万级回滚实测

| 阶段 | 结果 | 耗时 |
|---|---|---|
| 回填 10,000 | 10,000 账号/映射/角色/档案 | ~211 s |
| 一致性（strict） | **ok=true**，0 差异码 | — |
| 回滚 10,000 | 删除 10,000，**旧表 10,000 行未动** | **2.0 s** |
| 二次回填 | 恢复 10,000 | 211.27 s |
| 二次一致性 | **ok=true** | — |
| 批次审计 | backfill × 2 事件，`unbatched_flag=false` | — |

**关键**：回滚只删除了"被 `LegacyAccountLink` 引用的账号"，旧表完整保留；
回填与回滚都有批次事件可追溯。

## 2. 回滚语义（路径 A）

| 项 | 行为 |
|---|---|
| 回滚范围 | 全量（所有 link 引用的账号） |
| 预存账号 | 保留（无 link 者不删） |
| 旧表 | **不触碰** |
| 审计 | append-only，回滚追加事件 |
| 恢复成本 | 回滚 2 s / 重新回填 211 s（10,000 规模） |

## 3. 切换期数据处置（路径 A 特性）

路径 A 不切换 `AUTH_USER_MODEL`、不删旧表，因此：

- 切换后新增的"新表独有数据"（RBAC 角色、审计事件）在**配置回退后依然存在**（H2 已证）；
- 旧表仍是业务权威，新表是身份/权限层；
- **不存在"回滚丢数据"的路径**，因为回滚只是配置回退，不删数据。

这是路径 A 相对路径 B 的核心优势。

## 4. 故障注入（已覆盖）

| 场景 | 结果 | 出处 |
|---|---|---|
| 事务中途失败 | 整体回滚，无残留 | H2 drill |
| Profile 创建失败 | 单行回滚，其余继续 | G5 测试 |
| 重复回填 | `created=0`，不重复 | 万级脚本 |
| 重复回滚 | 追加新批次，不覆盖历史 | H1 测试 |
| 崩溃窗口（有业务无批次） | `find_unbatched_backfill` 可检出 | H1 测试 |

## 6. 结论

回滚在 10,000 规模下 2 秒完成、旧表零改动、二次回填可完全恢复。
**「回滚不丢数据」在路径 A 下是结构性成立**（配置回退而非数据回退），并已由万级演练佐证。
