## 9. 暗色模式（B06）

实现：`@media (prefers-color-scheme: dark)` 覆盖 `--ws-*` 基础令牌 + 三端强调色；把 9 处硬编码 `background: #fff` 改为 `var(--ws-surface)`（浅色等价）。

| 检查 | 结果 |
|---|---|
| 暗色快速视觉（17 页 × 390/1366 × 100%/150%） | **68 项 / 0 溢出 / 0 空页 / PASS** |
| 暗色无障碍（11 页，含主按钮对比度） | **0 问题 / PASS** |

截图：`.local/evidence/v2/phase/*-dark.png`（68 张）。

**发现并修复**：首轮暗色下“当前学期”卡片仍是白底——原因是 `body[data-workspace=...]` 的 `--ws-accent-soft` 字面浅色覆盖了 `:root` 暗色值；已在暗色媒体查询内为三端补对应强调色覆盖。

**局限**：跟随系统偏好，未提供手动切换；未做长文本/极端数据下的暗色抽查。
