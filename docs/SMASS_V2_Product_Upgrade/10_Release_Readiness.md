## 3. 生产上线前必须完成

1. **开启 MFA**：设置 `SMASS_MFA_ENABLED=1`，并完成系统管理员绑定演练；
2. **A02 收口**：统一 28 处深层 `has_action` 与产品守卫，避免同一角色能力不一致；
3. **A04 通知外键**：`Notification.recipient` 字符串改账号 FK（需迁移窗口 + 回填）；
4. **真实数据与支付**：均未接入，需独立授权与合规评审；
5. **部署安全**：DEBUG、密钥、ALLOWED_HOSTS、静态资源与备份策略。
